# Agent skills

Instructions an AI coding agent (Claude Code) loads for a task in this repository. Each folder holds a `SKILL.md`.

| Skill | Use it to |
|---|---|
| [finish-change](finish-change/SKILL.md) | Check that a change has its CLAUDE.md updates, a clean build and a screenshot check before a commit |
| [code-health](code-health/SKILL.md) | Measure complexity, size and copies against the enforced limits, and rank refactoring candidates |
